## 📌 Overview

This repository hosts my personal developer portfolio, showcasing my journey across **Software Engineering**, **Web Development**, and **Data Analytics & Data Science**. 

Built entirely with vanilla web technologies, the website highlights clean architectural structure, interactive UI elements, smooth cross-device responsiveness, and direct access to my production projects, certifications, and technical deliverables.

---

## 🚀 Key Features

* **⚡ Zero External Framework Bloat:** Built with lightweight semantic HTML5, modern modular CSS, and vanilla JavaScript for near-instant load times.
* **📱 Fully Responsive Design:** Fluid layout system using modern CSS Grid and Flexbox for seamless viewing across smartphones, tablets, and wide monitors.
* **📂 Dynamic Showcase Sections:**
  * **About Me:** Professional background, core technical focus, and engineering trajectory.
  * **Skills Matrix:** Categorized overview of languages, database tools, BI platforms, and web libraries.
  * **Project Gallery:** Featured repositories with live demos, code walk-throughs, and problem statements.
  * **Certifications:** Verified credentials and program completions.
  * **Interactive Contact:** Direct email and social connectivity channels.

## 💻 Local Development Setup

To run and inspect this portfolio locally:

1. **Clone the repository:**
```bash
git clone [https://github.com/sanskar00-debug/my-portfolio.git](https://github.com/sanskar00-debug/my-portfolio.git)

```


2. **Navigate into the project directory:**
```bash
cd my-portfolio

```


3. **Open in your browser:**
* Open `index.html` directly in any web browser, OR
* Serve with VS Code **Live Server** extension (`Right-click index.html` $\rightarrow$ `Open with Live Server`).
